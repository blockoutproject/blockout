# Politique de confidentialité

## 1. Responsable du traitement
Blockout Project (association de fait, non enregistrée)  
Contact : blockoutproject@gmail.com  

## 2. Données collectées
Blockout ne collecte pas de données personnelles nominatives, sauf si vous les fournissez volontairement via un email de contact.  

Des données techniques peuvent être collectées automatiquement pour le bon fonctionnement de l’application :  
- Modèle d’appareil et version du système  
- Version de l’application  
- Données de diagnostic (erreurs, performances)

## 3. Finalités
Les données sont utilisées uniquement pour :  
- Assurer le fonctionnement et la sécurité de l’application  
- Répondre à vos demandes de support

## 4. Partage
Les données ne sont pas vendues.  
Elles peuvent être partagées uniquement avec nos prestataires techniques (Hostinger, services de crash/analytics) dans le cadre du fonctionnement de l’application.

## 5. Conservation
Les données sont conservées uniquement le temps nécessaire aux finalités indiquées, puis supprimées ou anonymisées.

## 6. Vos droits
Vous pouvez demander l’accès, la rectification ou la suppression de vos données personnelles en écrivant à **blockoutproject@gmail.com**.

## 7. Modifications
Cette politique peut être modifiée à tout moment. La date en haut du document fait foi.
