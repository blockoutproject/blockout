# Contract inventory for the backend rebuild

Companion to the [baseline](../backend-preservation-baseline.md). This is an inventory of committed OpenAPI source at `e02a5cac12bf94a7163f7f2294739febc7cb56b9`, not a proposed API or a runtime authorization audit. Source links retain requiredness, nullability, enum values, parameter defaults, multipart shapes and error responses. Generated bundles and clients are projections; do not use this catalogue as a second contract source.

Inventory size: **130 operations** across 11 service contracts; **111 schema definitions**, including shared enums.

Operation rows list all request parameter names, direct body fields where inline, and referenced schemas. Schema rows list every declared property and inherited reference. A source schema without a direct mobile rendering consumer is retained as a transport boundary, not declared unused. Field purposes and fresh-data inputs are in the [data inventory](data.md).
