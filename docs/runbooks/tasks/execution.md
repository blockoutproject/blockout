# Task Execution

1. Confirm the claimed issue, scope, workset, source gate, and execution mode.
2. Read current context, the Blockout skill, applicable policies, and owning source.
3. Create a focused branch from the current integration branch.
4. Implement the smallest coherent change and preserve unrelated work.
5. Run risk-proportionate Nx, Maven, Expo, Python, Docker, environment, and diff validation.
6. Stage explicit paths, commit in English, push, and open a draft PR.

Production changes additionally require the migration policy, one-deployable scope, shadow evidence, explicit cutover,
and rollback. Draft publication never authorizes merge or deployment.
