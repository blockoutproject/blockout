# Task Acquisition

Use this when the developer wants new work to continue.

1. Perform fresh discovery.
2. Select the highest valid compatible Ready issue.
3. Assign exactly the authenticated user and move it to In Progress.
4. Reread the issue, Project item, dependencies, and conflicting worksets twice.
5. Continue only when ownership and state are stable.

Do not create a branch, plan implementation, or edit task files before the claim succeeds. If no Roadmap Project is
configured, report that acquisition is unavailable rather than inventing a local claim system.
