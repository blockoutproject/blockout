# Task Discovery

Use this only for read-only selection after a Blockout Roadmap Project exists.

1. Run `git status --short --branch`.
2. Read the Blockout best-practices skill and current context.
3. Read the complete live Roadmap through the compact helper.
4. Consider only valid, unassigned, non-Epic Ready issues.
5. Check dependencies, active worksets, current source, and equivalent delivered work.
6. Return the first compatible task with source gate, risks, validation, and expected workflow.

Do not assign, edit, branch, commit, push, or infer work from Markdown when the live Project is unavailable.
