# GitHub Roadmap Policy

Use the GitHub Project as task authority only after a Blockout Roadmap Project has been explicitly configured.

- Discovery is read-only.
- Acquisition selects and assigns one executable issue before editing.
- Execution preserves the issue scope and workset.
- Draft pull requests target `develop`.
- Merge requires separate authorization and current validation.
- Documentation does not make backlog work executable by continuity.

The compact Project reader defaults to organization `blockoutproject` and requires
`ROADMAP_PROJECT_NUMBER` when no default Project has been established.
