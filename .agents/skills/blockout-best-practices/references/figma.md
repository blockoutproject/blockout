# Figma

- [`Blockout - Product Design`](https://www.figma.com/design/NwDQmiXqSjKVzQ6gwry0zb) is the only canonical design file.
- Use existing components and established tokens when they cover the required structure. Never detach an instance or redraw an available primitive.
- Preserve the current dark Blockout direction, Outfit typography in the application, and the source-backed Material Community Icons or Ionicons families.
- Cover iOS, Android, relevant states, focus, touch targets, text scaling, safe areas, and readability.
- Record exact nodes, runtime dimensions, and screenshots as issue evidence and obtain explicit human approval before closing.
- A Figma-only delivery has no documentation pull request.
