## Commit and deferred work

A concrete coordinator around the sport use case calls sport, search's dirty-revision interface and notification's eligibility/consumed-work interface within the same PostgreSQL transaction. Instantiate only the interfaces required by actual collaborating modules; no empty bus, listeners or event registry. Failure of a required local participant rolls back that match's coherent transaction. In-memory stubs qualify F02 isolated tests, but do not constitute cross-feature acceptance.

The coordinator compares accepted semantic before/after facts: no-op replay creates no new revision/work. A changed source freshness timestamp alone is not a new result announcement. A newly accepted result includes import origin, and F07 must suppress historical reconstruction announcements. F07 owns match-level live/result/replay facts and event composition; ordinary corrections do not reannounce consumed events. External push, search HTTP, storage and provider calls happen after SQL commits through each owner's actual processing. This does not introduce persistent push retries. No exactly-once transport claim.

Classification, restrictions, names, contact suppression, locality and logo changes mark all actually affected searchable/presented resource revisions, including inherited club logos for teams. F04 can coalesce to current state. Changing an index record or cache never changes sporting visibility.

## Privacy and diagnostic contract

Allowed diagnostics: environment, source/family, nonpersonal scope/resource IDs, cycle/order, accepted/unchanged/rejected counts, safe reason code, current integration outcome and opaque diagnostic ID. No request bodies, provider documents, contact values, referee names, secrets or personal address/candidate history. Persist only current useful attribution and F01/F13-owned diagnostic state within F11 retention. A successful download never reports complete integration or closes its incident by itself.

F07 records result composition at the accepted match transition: a currently public link yields result plus replay, including after live; otherwise a later link publication yields a separate replay event. Match-level processed announcement facts, rather than permanent per-recipient history, prevent ordinary repeats. F07 owns audience selection, best-effort push and the accepted exceptional-duplicate limitation after restoration loses match facts. No bus or provider call is added inside the transaction.
