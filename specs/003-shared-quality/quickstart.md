**Scope**: [plan](plan.md), [contracts](contracts/README.md), [data ownership](data-model.md).

## Prerequisites

The initial executable workspace and its Maven/npm/Nx commands are documented in the [README](../../README.md#verification). Setup provides application launchers, local PostgreSQL and development checks. The integrated scenarios below still require their owning implementation and actual qualification; startup and JavaScript exports alone do not satisfy them.

Use the selected dependency versions, isolated test data and the required test environments/devices. ## Contract boundary

With the canonical roots and selected generator configuration present, lint and bundle each root using Redocly; generate backend interfaces/DTOs, collector RestClient and mobile Query/Zod output at the same revision. CI runs the owning Maven compile/tests and mobile typecheck/Jest targets from a clean checkout.

When introducing or changing a generator or its configuration, also regenerate from clean output directories, compare normalized results and verify that generated outputs remain ignored. Record the outcome in the PR. This targeted qualification avoids a second generation on every CI run. Expected: reproducible output, no generated source committed, no template patch and all actual consumers compile.

Exercise actual HTTP entry/decoding paths, not only schemas in isolation. Backend request tests cover required/optional/nullable/empty values, nested unknown properties, wrong types, enums/dates, safe Problem Details and refused effects. Mobile tests cover generated-schema validation once before Query success/cache, malformed/partial JSON, additive responses, 204/non-JSON, cancellation and bounded timeout. For cancellation, exercise Expo Fetch’s native rejection and the adapter’s error translation; do not require an application workaround for a Fetch implementation that ignores its AbortSignal.

For the collector, exercise valid nullable/additive responses through the configured generated client, native decoding failures, partial sporting outcomes, bounded waits and uncertain-write failure without replay. Verify actual backend serialization of required fields, including runtime null, target pagination and outcome counts. The [accepted decoding limits](contracts/README.md#source-composition-and-generated-outputs) do not promise exhaustive rejection of invalid backend data; do not test that upstream gaps must persist or introduce compensating validation. After removing runtime validation, inspect a clean collector package to confirm that its validator dependency and runtime contract resource are absent. Generator requirements and mobile schema admission still need their own qualified paths; no unchecked mobile cast is authorized.

## Authorization and session

Run `npx nx run backend:test` and `npx nx run collector:test` for the shared security boundary. `SecurityWebMvcTest` verifies real JWT signatures, issuer/audience/expiry, client and scope refusals, safe 401/403 and public exceptions. `IngestionAuthenticationIntegrationTest` verifies the actual generated client, Boot registration and native OAuth cache against controlled token/business endpoints: reuse, shorter expiry, bounded renewal failure and no rejected/uncertain write replay. These fixtures establish shared framework wiring, not real Auth0 settings or owner-specific business authorization.

Use controlled visitor, ordinary, authorized and different-owner identities across both environments. Call protected operations directly with missing/expired/wrong-issuer/wrong-audience/wrong-client/scope-limited tokens. Expected: missing or invalid credentials return 401 with a Bearer challenge; authenticated client/scope/permission refusals return 403, with no prohibited business effect or disclosure. Keep F05's explicitly accepted token-validity limits and F09 SDK entitlement authority; do not test invented instantaneous global revocation.

Delay account A's response; sign out or switch to B; deliver the old result after attempted cancellation. Expected: A's private state cannot enter B's cache or become usable. Fail remote logout and verify local cleanup. Lose a mutation response, renew credentials or reconnect network: no automatic mutation replay. F03 accepted explicit/navigation/foreground refresh still works, and F07 expiration applies without network.

## Frontend mutation qualification

The [complete inventory](research.md#frontend-mutation-inventory) covers every implemented HTTP write and local/native family. Compare each consumer with the [responsibility sequence](plan.md#frontend-mutation-conventions), including unchanged families whose contracts justify their disposition. New UI commands must join their matching family rather than introduce another convention.

| Transition                                                      | Required observable evidence                                                                                                                                                                                                                                       |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Invalid intent / cancelled or dismissed confirmation            | No transport or storage write, draft retained; held native callbacks cannot confirm twice or act after disposal.                                                                                                                                                   |
| Same-turn double action / sibling command / media selection     | One resource command before the next render; the executing action shows busy; its siblings are disabled. Picker and submit exclude each other in both invocation orders.                                                                                           |
| Credentials pending / revoked grant / changed session or target | Current session and live cached authority checked again before I/O. Late results cannot publish into another account, navigate a removed route or replay old feedback.                                                                                             |
| Certain refusal / validation                                    | Editable draft survives; field refusal stays beside the field; other safe failures use the single transient Error Toast. No automatic command retry.                                                                                                               |
| Lost acknowledgement / stale revision                           | Write remains blocked through navigation, draft discard and remount; a fresh accepted reread is required. Failed, cancelled or older rereads do not unlock. Reconciliation preserves dirty intent and does not synthesize command success.                         |
| Successful write / cache                                        | Accepted data updates the correct resource. Late numeric revisions cannot replace newer observations; incomparable opaque revisions are preserved conservatively. Only canonical related queries are invalidated. Dirty state clears only for the accepted draft.  |
| Native/local completion                                         | Storage acknowledgement alone advances installation gates; native handoff never proves external completion. Borrowed picker copies are released after preparation; the prepared copy survives outstanding upload until both draft and transport owners release it. |
| Contract-specific outcomes                                      | F06 retains one bounded uncertain-result observation and explicit absolute-state retry; F05 establishment uses the newly authenticated generation; F09 retains provider-owned purchase/restore/association outcomes.                                               |
