Run the [repository verification commands](../../README.md#verification) for the implemented input foundation. Backend tests exercise generated JSON/multipart binding, canonical metadata constraints, exact/over-limit file and complete request sizes, the approved decoded-buffer budget, private temporary cleanup and configuration diagnostics. ## Prerequisites

Use F13's selected Java/Expo dependencies and generated clients. Provide an isolated private support repository, pre-created intake labels, a repository-scoped server token, CLI 2.102.0 and a private Discord webhook. Verify the token's actual attachment permissions and authorized/unauthorized image access before using real support content. Use fictional contact, text and image fixtures. Confirm the provider procedure for exceptional image erasure; issue closure is insufficient evidence.
