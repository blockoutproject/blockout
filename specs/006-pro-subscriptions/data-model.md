# Data model: Pro entitlements

These are logical ownership and mobile-consumption concepts, not database entities. F09 creates no table or migration.

| Concept                      | Source and meaningful fields                                                                                                                                | Lifecycle and validation                                                                                                                                                                                                                                                                                                                                       |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Usable account context       | F05 native principal and business UUID in the mounted private lifetime                                                                                      | Available only after usable-account establishment. No email-derived ID. Session replacement clears previous rights/UI and rejects old outcomes.                                                                                                                                                                                                                |
| Customer association         | Native SDK App User ID for the UUID; latest desired session and one in-flight identity call                                                                 | Identity calls complete sequentially. Only successful current association admits provider operations. Anonymous native logout state grants no Blockout guest rights or purchase permission.                                                                                                                                                                    |
| Pro entitlement              | Current-account CustomerInfo, active `Blockout Pro` and supported origin/validity/renewal fields                                                            | SDK owns active/inactive status, cache and expiry. No separate rights ledger, grant union or expiry calculation.                                                                                                                                                                                                                                               |
| Native operation fact        | Cancellation, SDK-pending payment, ordinary error, confirmed payment, supplied current CustomerInfo                                                         | Distinct from entitlement activation. Standard native failure feedback permits later explicit native action without duplicate app messages without an app Verify state or mandatory read. View removal creates no cancellation or global busy reservation; listener/foreground reads survive. No persisted transaction journal or replay.                      |
| Paywall host                 | Explicit resolved existing `default` offering, same published `Blockout Pro` Paywall and current associated owner                                           | One standard React Native Modal containing only official Paywall, for free/paid/gifted/unknown accounts. Missing/failed opening gives source-screen feedback. Close, logout, accepted erasure and account replacement remove the host. No commercial route or catalogue Query.                                                                                 |
| Offer                        | Same existing RevenueCat project, `default` offering, published `Blockout Pro` Paywall, native products/entitlement/platform keys and localized store terms | No fallback to current or hardcoded price. Entry is independent of rights; existing banner encouragement remains restricted to known inactive rights without unresolved payment facts. Subscriber controls and original-store/assistance behavior remain standard native UI; actual limitations are accepted/reported without custom admission or replacement. |
| Gift / assisted intervention | Supported owner RevenueCat operation and private F10/F11 evidence                                                                                           | Verified beneficiary/scope; inspect an uncertain intervention before repeating. Independent of billing; no gift ledger or sensitive public record.                                                                                                                                                                                                             |

## State consumption

| Current-account evidence                            | Explicit Pro presentation                                                                                                       | Advertising / premium chrome                                                    |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Guest                                               | Shared invitation without offer/price; ordinary sign-in never reopens Pro                                                       | No inherited rights; F11 owns guest eligibility                                 |
| No usable account or association pending/failed     | Useful account/association prerequisite; brief source feedback on failed opening and later explicit entry                       | No old-account rights, ads or premium styling                                   |
| SDK-active paid or gifted                           | Same standard native paywall and supported configured actions; visible generic Buy controls and native limits accepted/reported | No Blockout ads; current approved Pro chrome; no added banner                   |
| SDK-inactive                                        | Same paywall with provider products and actions                                                                                 | F11 may allow ads; existing eligible banner; no premium chrome                  |
| No current SDK rights information                   | Same voluntary paywall entry after association; no app verification page                                                        | No ads, banner or inherited premium chrome                                      |
| SDK-pending or confirmed payment without activation | Native facts and recognition/restore/assistance; no Verify/replay path                                                          | No new right inferred; preserve independent rights and suppress purchase banner |

External changes become visible through ordinary SDK refresh rather than a propagation deadline. Account/view departure discards presentation, not a store transaction. [F05](../005-accounts-identity/data-model.md) owns deletion and historical references; restoration never resurrects erased profile data or gifts. Provider action/configuration limits remain qualification limits rather than additional Blockout state.
