# Blockout Design Direction

Blockout does not yet have a migrated canonical design-system document or canonical Figma file.

Until the mobile architecture and design-system roadmap items are complete:

- treat the current Expo application as the delivered visual baseline;
- preserve existing navigation, layouts, assets, colors, typography, and interaction behavior during structural work;
- do not import Maaatch web visual decisions into Blockout;
- do not create a parallel canonical Figma file or design system by inference;
- record design-system migration work under the active roadmap before changing durable visual rules.

This file intentionally occupies the same repository role as Maaatch `DESIGN.md` while documenting the current
Blockout evidence boundary.
