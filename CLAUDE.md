# Blockout Agent Guidance

Repository skills live under `.agents/skills/*/SKILL.md`.

Start with `.agents/skills/blockout-best-practices/SKILL.md`. Load the additional skills and policy references it routes
to only when the current task triggers them.

The generated V1 contracts are the active transport authority. The organization
[Roadmap Project](https://github.com/orgs/blockoutproject/projects/4) is the only operational task and claim authority.
Follow the Blockout skill and the applicable task runbook before selecting, claiming, executing, or releasing work.
